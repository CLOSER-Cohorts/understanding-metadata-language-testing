# Comprendre les métadonnées

## Apprentissage autonome par l’équipe Métadonnées de CLOSER

Cette ressource évolutive a été développée par l’équipe Métadonnées de CLOSER afin de créer des supports pédagogiques et de perfectionnement pour améliorer la compréhension des métadonnées et ainsi favoriser une meilleure utilisation et compréhension des données de recherche.

[Commencer le cours d’introduction](<introduction/1.0 Module Introduction.md>){ .md-button }

### Améliorations et bugs

Si vous trouvez des erreurs ou souhaitez suggérer des améliorations, veuillez [soumettre un ticket sur le dépôt GitHub ici](https://github.com/CLOSER-Cohorts/understanding-metadata/issues). Nous vous ajouterons à la liste des contributeurs.

### Retour sur le cours

Nous menons une *courte enquête* afin d’obtenir un retour plus général. Si vous pouvez consacrer 10 minutes pour la remplir après avoir consulté le cours, cela nous serait très utile.

[Laissez votre avis](https://qualtrics.ucl.ac.uk/jfe/form/SV_a4y7ldYQWtpY9AG){ .md-button }
